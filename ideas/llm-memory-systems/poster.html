LLM 记忆系统演化：从 ChatGPT 到 Memory OS 与 Neural Memory

研究对象：跨会话个性化、RAG 外部记忆、Agent Memory、LoRA/参数化记忆、Tensor/Latent/Neural Memory、近期纯文本压缩与 Benchmark。
核心论点：没有单一路线“解决记忆”。可落地系统会组合短期上下文压缩、可审计外部记忆、图谱/Agent memory、参数化技能内化与底层 neural/tensor memory。
调研日期
2026-06-03

范围
以 2022 ChatGPT 发布后为主，简述 REALM/RAG/RETRO 等前史。

目标
建立技术脉络、代表论文/项目索引、评估陷阱和 2026 可落地架构。

1. 演化时间线

2020 前史

知识增强而非长期记忆。 Memory Networks、kNN-LM、Transformer-XL、Compressive Transformer 为外部记忆和长上下文提供概念基础。

2020-2021

检索增强预训练/生成。 REALM、RAG、RETRO 让模型在生成时访问外部知识；核心是 knowledge access，不是跨会话 personalization。

2022

ChatGPT：上下文即记忆。 早期体验依赖当前窗口，跨会话记忆弱；工程补丁是 conversation buffer、rolling summary、profile note。

2023

Agent memory 兴起。 Generative Agents、MemoryBank、LongMem、MemGPT 把 memory stream、reflection、planning 和 virtual context 带入 agent。

2024

产品记忆与评估出现。 ChatGPT Memory、LoCoMo、LongMemEval、MemoryLLM、ICAE、MemLLM；长期记忆开始被产品化和 benchmark 化。

2025

Memory layer / OS 化。 Mem0、A-Mem、MemOS、Zep/Graphiti、LightMem、MIRIX、BEAM；RAG 向 graph、temporal、agentic memory 过渡。

2026

自进化与可治理。 EverMemOS、MemRL、TierMem、TencentDB Agent Memory、AgentMemoryBench、LongMemEval-V2；焦点转向生命周期、溯源、遗忘、经验学习。

2. 第一代记忆：上下文与纯文本压缩

机制

把历史直接放进 prompt，或压缩成可读摘要、profile、project notes、session replay。它是最便宜、最可审计的一层。

代表

LLMLingua LongLLMLingua Selective Context Gist Tokens ICAE ACON Memento

关键判断

  • 摘要会改变证据权重，反复 compact 会造成“记忆腐化”。
  • 高质量压缩应保留 raw log 或 evidence pointer。
  • 2025-2026 重点从 prompt compression 转向 agent context compaction。

3. 产品级记忆

产品定位边界
ChatGPT Memorysaved memories + reference chat history；跨会话个性化更像用户画像和偏好层，不是完整 agent memory OS
Gemini recall past chats使用历史对话恢复上下文偏连续工作流，而非显式记忆对象管理
Claude memory面向 Team/Enterprise 的工作上下文记忆强调企业控制、incognito、导入/导出和治理
产品记忆的风险：用户常看不到完整写入和检索过程；错误、敏感和过期记忆需要显式治理。

4. 五条主路线：记忆不止一种

上下文
压缩

短期工作记忆。 通过 summary、memento、auto-compact 和 soft tokens 降低上下文成本；适合 coding agent 和长任务恢复。

RAG
图谱

可审计事实记忆。 vector/hybrid search、rerank、GraphRAG、Zep/Graphiti；强在可删、可更新、可引用。

Agent
Memory

行为连续记忆。 memory stream、reflection、procedure、failure experience、self-editing memory；影响 agent 决策和任务执行。

LoRA
参数

内化技能/风格。 SFT、LoRA、adapter、model editing、continual learning；适合稳定高频技能，不适合敏感动态事实。

Tensor
Neural

隐空间长期依赖。 Gist Tokens、ICAE、MemoryLLM、Titans、MIRAS、MSA；潜力高，但审计、删除和权限隔离仍弱。

Memory = 写入过滤 + 表征结构 + 检索编排 + 冲突处理 + 遗忘治理 + 评估观测

5. RAG → Graph Memory → Memory OS

RAG 的贡献

把知识外部化；允许更新、删除、引用和权限控制。适合企业文档、业务实体和动态事实。

RAG 的误区

检索命中不等于系统真的记住；top-k chunk 缺少时间、冲突、主体和生命周期。

Graph Memory

把事实组织成人、项目、事件、关系、时间边；Graphiti、GraphRAG、LightRAG、HippoRAG 是代表。

Memory OS

把 plaintext、activation、parametric memory 统一成可治理资源；MemOS、EverMemOS、MemoryOS 是代表。

代表项目谱系

MemGPT/Letta MemoryBank A-Mem LightMem Mem0 Zep/Graphiti MemOS EverMind/EverOS TencentDB Agent Memory

6. 可落地混合架构

事件日志append-only：原始对话、工具调用、文件状态、失败分支；用于审计和回放。
短期工作记忆当前任务窗口 + compacted state；只保留当前子任务需要的信息。
事实/图谱层atomic facts、entities、relations、time edges、provenance、permissions。
Agent 经验层procedures、failure cases、tool gotchas、user feedback、reflection。
参数化层稳定风格、模板、领域技能才进入 LoRA/adapter；保留回滚来源。
Neural/Tensor 层memory token、KV/activation、FFN memory、test-time neural memory；作为底层增强。
治理层写入过滤、去重、冲突、过期、删除、敏感信息策略、memory poisoning 防御。

7. 参数化与 Tensor 内化

LoRA / 参数化记忆

路线适合风险
SFT / LoRA稳定风格、领域模板、procedure难删、难审计、组合冲突
Model Editing局部事实修正locality、泛化、邻近事实破坏
Continual Learning长期任务适应灾难性遗忘、数据污染
Sleep Consolidation把验证后的外部经验巩固为技能错误记忆被固化

Tensor / Neural Memory

类别代表判断
Soft tokensGist Tokens、ICAE高压缩，低可读
Activation/KVPagedAttention、context cache工程成熟，但不是长期记忆
FFN memoryMemoryLLM FFN可分析参数记忆的研究入口
Test-time memoryTitans、MIRAS、MSA前沿潜力高，治理能力弱
边界：参数和 tensor 内化适合稳定技能与底层能力增强，不适合用户可删事实、企业审计和多租户权限隔离。

8. Benchmark 与评估陷阱

Benchmark能力注意事项
LoCoMo多 session 对话 QA、事件总结容易被 prompt/context 策略影响
LongMemEval时间推理、知识更新、拒答现代长上下文可能削弱区分度
BEAMup to 10M tokens、10 类能力成本高，生成数据需审慎
MemBenchfactual + reflective memory需看是否贴近真实 agent
MemoryAgentBenchretrieval、test-time learning、conflict新 benchmark，复现生态早期
AgentMemoryBenchsystem/personal memory、repair、transfer更完整但比较成本高

必须同时测

写入准确率 回忆准确率 冲突处理 遗忘执行 任务收益 成本曲线 可观测性 安全性

陷阱：LLM judge 偏差、答案键错误、只测检索不测生命周期、上下文窗口作弊、自报 benchmark 不等同 SOTA。

9. 2026 展望

  1. 记忆系统会平台化：Memory OS / memory layer 成为 agent 基础设施，而非 prompt 小技巧。
  2. 外部记忆仍是主干：审计、删除、权限、来源要求决定 RAG/graph/plaintext 不会消失。
  3. 参数化只做后端巩固：稳定、高频、低隐私风险的技能才适合 LoRA/adapter。
  4. Neural memory 会增强底层能力：超长上下文、多模态和 test-time learning 是主要落点。
  5. 竞争点转向治理：写入过滤、冲突解决、选择性遗忘、溯源、安全和长期稳定。

10. 结论

LLM 记忆的演化不是“更长上下文”一条线，而是从 context engineering、RAG、agent memory、Memory OS、参数内化到 neural/tensor memory 的多层系统演化。

最现实的架构是混合式：文本压缩负责成本，RAG/图谱负责可审计事实，agent memory 负责行为连续，LoRA/adapter 负责稳定技能，neural/tensor memory 负责底层长程依赖和压缩。
