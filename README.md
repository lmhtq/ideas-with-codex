# ideas-with-codex

This repository collects independent ideas developed with Codex and packages their final presentation artifacts for sharing.

## Ideas

### LLM Memory Systems

A research-oriented deck and academic poster about the evolution of memory systems for LLMs, covering context windows, RAG, long-term memory, agent memory, LoRA-style adaptation, and emerging memory architectures.

- [PowerPoint deck](ideas/llm-memory-systems/deck.pptx)
- [Deck preview](ideas/llm-memory-systems/deck-preview.png)
- [Academic poster PDF](ideas/llm-memory-systems/poster.pdf)
- [A0 poster PDF](ideas/llm-memory-systems/poster-a0.pdf)
- [Poster preview](ideas/llm-memory-systems/poster-preview.png)
- [Research notes](ideas/llm-memory-systems/research-notes.md)

### LLM Memory Imagegen Academic Deck

An image-heavy academic presentation exploring the same LLM memory theme through generated visual slides.

- [PowerPoint deck](ideas/llm-memory-imagegen-academic/deck.pptx)
- [Deck preview](ideas/llm-memory-imagegen-academic/deck-preview.png)

### NexusKin X01

```text
ideas/
```
